# Woodshed plain-language guide

Everything a student reads should feel easy for a **7th-grade piano student** (about 12–13 years old) who reads music slowly and is new to jazz. Adults benefit too. Same music, simpler words.

## Voice
- Talk to the student as "you". Calm, friendly coach. Present tense, active voice.
- No baby talk, no hype, no exclamation marks, no jokes that need explaining.
- Plain and specific beats clever.

## Sentences
- Aim for 8–14 words. Never more than 25.
- One idea per sentence. Split long sentences with periods.
- No semicolons. No em dashes (—). Avoid long parentheses; make them their own sentence.
- Numbers as digits ("3 times", "8 drops").

## Words
Use the everyday word:

| Instead of | Write |
|---|---|
| objective | goal |
| prerequisite(s) | what you need first |
| retrieval / retrieve | play it from memory |
| consolidate / consolidation | make it solid |
| evidence | what you can actually play / proof |
| provisional | first draft / for now |
| harmonize | put chords under |
| application (of a skill) | try it in music |
| transfer | move it to a new key |
| articulation | short or smooth notes |
| demonstrate | show |
| sufficient | enough |
| approximately | about |
| subsequent | next |
| utilize | use |
| indicates | shows |
| simultaneously | at the same time |
| independence (of hands) | each hand doing its own job |
| spaced review | coming back to it a few days later |
| diagnostic / assessment | check |
| adaptation (source label) | keep the label word, explain simply around it |
| verify / verified | check / checked |
| repertoire | pieces |
| tension | tight muscles |

## Music terms
- Keep the real term. Students should learn it. But never leave it unexplained.
- The site has a glossary (`src/content/glossary.ts`). Terms listed there get a tap-to-see definition automatically, so use them **exactly as spelled there** (for example "guide tones", "sixth-diminished scale", "diminished chord", "sixth chord", "movement", "swing", "riff", "chorus", "form", "bridge", "changes", "comping", "voicing", "dominant seventh", "invention", "subject", "tempo", "octave", "fingering", "click on 2 and 4", "by ear", "transcription", "bebop", "arm weight", "baseline", "check-in", "essential version").
- For any other music term, explain it in a few plain words the first time it appears in a passage.

## Never change
- Note names with octaves (C4, E♭3, A♭4), chord symbols (F7, C6, B°, Cm6), fingerings (1-2-3-4, "finger 3"), tempo marks (♩ = 60), counts, minutes, dates, times.
- IDs, skills, kinds, notation, keyboard specs, tempo numbers, reps numbers, durations.
- Song titles, names, labels, record dates and personnel, URLs, and the facts in source notes. You may reword around a fact, never drop or change it.
- What the student practices. Same instructions, simpler words. Don't add or remove steps.

## Examples
- Before: "Hear, sing and play Barry Harris's C sixth-diminished scale as a right-hand line."
  After: "Learn Barry Harris's C sixth-diminished scale. Hear it, sing it, then play it with your right hand."
- Before: "Retrieval: The C sixth-diminished scale, Invention No. 1: the subject."
  After: "From memory: the C sixth-diminished scale and the Bach subject."
- Before: "Two threads get real time: Harris movement and the left hand's first blues work."
  After: "Most of today goes to two things: Harris chord movement and your first blues in the left hand."
